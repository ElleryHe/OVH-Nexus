每当 OVHcloud 准备推出新一代服务器或限量闪购机型（例如 `27skle01-v1`、`27risele01-v1`）时，机房往往会提前数小时甚至数天将机器上架，并把新 SKU 写入公开接口 `/dedicated/server/datacenter/availabilities`（此时状态通常为 `unavailable` 预上架未开售）。

**公开货架 SKU 变动监控（`internal/monitor`）** 全天候在后台扫描全量公开货架，让您在新机型正式开售前第一时间捕获情报并提前建好采购任务。

## 防误报与三态全生命周期追踪引擎

由于 OVHcloud 公共接口偶尔会出现 CDN 缓存回退或临时返回残缺数据，为确保精准追踪货架变化并彻底杜绝“假下架/假上新”刷屏告警，监控引擎内置了多层核心机制：

1. **首轮存量基线静默 (`baseline: true`) 与三态生命周期追踪 (`presale` / `announced` / `listed`)**：
   - 首次部署初始化（或切换监控的 OVH 区域端点）时，系统将当前已存在的全部机型写入 `/data/nexus.db`（`sku_watcher_state`）并标记为存量 `baseline: true`，**既不发送首轮刷屏通知，也不会将存量机型误标为“新上架”**。
   - 扫描仅拉取 `eco` 与 `baremetalServers` 两个独服公开目录中的真实 `planCode`（`RealPlans`，与 VPS 目录隔离且严格剔除 `baseCode`/`product` 元数据别名污染），并与实时库存接口比对：
     - **`presale`（预售 / 预上机架）**：已出现在实时机房库存接口中，但尚未写入公开价格目录（记录 `presaleSince`）。
     - **`announced`（已公布未开售）**：已写入公开价格目录（含定价与标配），但实时库存接口中尚无任何配置（典型如 `KS-LE`、`RISE-LE`、`SYS-LE` 等限量版机型）。
     - **`listed`（正式在售）**：同时存在于公开价格目录与实时库存接口（记录 `listedAt`）。当一款机型从 `announced` 首次进入实时库存接口时，系统会自动生成一条带 `saleStarted: true` 的 `added` 记录并推送**正式开售（Sale Started）**提醒。
2. **同产品线换代 (`replaced`) 智能合并与分组聚合通知**：
   - 当同一产品线（相同商业型号名称 + CPU，例如 `SYS-2 | Intel Xeon-D 2141I`）在同一轮扫描中出现旧代码消失、新代码上架（如 `24sys022 -> 24sys02-v3`）时，系统会自动将其合并为单条 **`replaced`（换代）** 记录（携带 `replacedFrom: "24sys022"`），不再同时误报新增与下架。
   - 推送的 `sku.changed` 通知消息按 **`🆕 新增`、`🚀 开售`、`🔄 换代`、`➖ 下架`** 四个区块，并在每个区块内按产品线聚合展示。
3. **20 秒快速复核确认下架 (`missingCounts >= 2`)**：
   - 当某个已知 SKU 在单次扫描中消失（`missingCounts == 1`）时，系统不会立即判定为下架，也不会干等下一个完整扫描周期，而是自动调度一次 **约 20 秒后的快速单独复核**。
   - 只有当 20 秒复核确认该 SKU 仍然缺失（`missingCounts >= 2`）时，才会立即标记为 `removed`（确认下架）并发送通知；若恢复出现则计数归零。
4. **单轮锐减 >30% 异常熔断与区域变体去重 (`skuMergeRegional`)**：
   - 若单次接口返回的 SKU 总数相比上一轮**骤降超过 30%**（当基线数量 `>= 5` 时），系统直接判定本轮为上游 API 临时异常并跳过比对。
   - 开启 `skuMergeRegional`（默认开启）后，会自动将 `-sgp`、`-syd`、`-mum` 等区域后缀变体归并处理，避免同一款机器因多区域目录同步产生重复通知。

## 可配置的监控规则

在 **库存与 SKU 监控（`/monitor`）** 或 **通知中心（`/notifications`）** 中，您可以灵活调整：

| 配置项 | 字段名 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| **启用 SKU 变动监控** | `skuEnabled` | `true` | 是否开启后台定时独服货架扫描（无需 OVH API Key）。 |
| **扫描间隔 (秒)** | `skuInterval` | `120` (2分钟) | 轮询扫描周期（最小支持 `60` 秒；已保存的旧默认值 `600` 秒会自动迁移为 `120` 秒）。 |
| **关注产品线** | `skuRanges` | `["KS","RISE","SYS","ADV","SCALE","HGR"]` | 按产品家族过滤需要通知的机型。 |
| **追踪子配置级变动** | `skuTrackConfigs` | `false` | 开启后，当已有型号新增或移除特定的 `内存 + 硬盘` 组合时也会触发通知。 |
| **合并区域后缀变体** | `skuMergeRegional` | `true` | 自动归并 `-sgp` / `-syd` / `-mum` 区域变体。 |

## 查看 SKU 变动时间线

在 **库存与 SKU 监控（`/monitor`）** 与 **实时库存矩阵（`/availability`）** 中，均展示了 **SKU 变动时间线**（持久化于 `/data/nexus.db`，并可通过 MCP 网关 `catalog_sku_changes` 工具供 AI 查询），清晰展示变动时间、状态徽标（**新上架**、**已公布未开售**、**预售**、**开售**、**换代 (`oldCode → newCode`)**、**确认下架**）、友好商业型号、CPU/内存/存储规格与不含税月付价格。
